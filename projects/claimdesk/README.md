# 青途保 · 理赔初审台

虚构「青途保」运费险 / 小额意外险的初审队列。Agent 写案件状态，不触发打款。

**没有引用，就先不答。** 适用**出险日**条款版本，不用投保日印象。演示永不打款（`NEVER_PAYOUT`）。

## 先听五分钟：初审在干什么

青途保是虚构的运费险 / 小额意外险。顾客不是来聊天的，是来报一笔已经发生的损失。没做过理赔也没关系，先当听表哥讲柜台上的规矩。

**三步，别跳。**

- **报案**：把出险经过、保单、照片交进来，案子立上。
- **补件**：缺运单、缺签收图、缺发票，先列清单。材料不齐不审结。
- **核赔**：对照条款写建议——通过、拒赔、差额或复议。建议不是打款。

**出险日不是投保日。** 5 月买的保单、8 月墨水瓶碎了，要看瓶子碎的那天用哪一版条款，不能因为「我投保早」就用旧版「易碎赔 50%」。条款改过，改的是出险当天那本。

**免赔额。** 意外险每次先扣 ¥50，再谈赔多少。申请 ¥80、免赔 ¥50，建议赔 ¥30。运费险免赔是 0。式子要写进决定书。

**店铺已经退过，保险不能再全额赔。** 店退了 ¥8、保险申请 ¥20，最多看差额 ¥12。店已经退够了，冲减到 0，建议拒赔——同一笔损失不能拿两份钱。

**为什么没条款就拒审。** 叙述对不上任何一条，就亮红条「没有引用，就先不答」。不能猜、不能按「看起来像」放行。没条款的通过，是假通过。

## 三个角色

| 角色 | 写入 | 禁止 |
| --- | --- | --- |
| 材料质检 | 缺件清单 | 材料不齐还审结 |

主管按固定顺序写账，不是五人 Mesh。
