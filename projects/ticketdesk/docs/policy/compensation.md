# 青匣记物流查询与补偿口径

生效: 2025-06-01
失效:
优先级: 日常
文档编号: QX-POL-补偿口径-2025

## 1. 物流查询

订单查询工具返回的轨迹，是给客服看的事实，不是给模型编造的。查询失败时写「查不到订单」，不要猜签收。

## 2. 可引用的补偿

日常：72 小时未更新 → 催件，不赔运费（见日常售后第 2 条）。

活动窗口内：48 小时未更新 → 可起草 ¥12 以内运费补偿（见盛夏大促第 1 条）。必须同时点名活动文件路径。

质量破损：未使用且有开箱照片的，可起草退货退款；金额仍受 200 元执行闸门约束。

## 3. 人点执行

所有补偿、退款、改地址，下一动作都是「等人点执行」。演示环境的支付接口不接受 `confirm=true`。
