# 默认日历（不要自己改成「先自学三个月再来」）

读者默认是**有基础的小白**：会写一点 Python（函数、列表、`if`），用过 ChatGPT，或至少成功调用过一次 LLM API。
还不会 Python 的人：先花一周 **Week -1**（venv、函数、读报错）。那一周**不算**在下面的 8 周里。

默认路径只有这一条，不用选：

**8 周 · 每周 5–6 小时 · 合计约 43 小时 · 大约两个月。**

建议节奏：两个工作日晚上各 1.5 小时 + 一个周末块 2–3 小时。

做完得到的是一份能讲清取舍的作品集，**不是**一份录用通知。

只给「每周能拿出一整块晚上 + 一个完整周末」的人。两个毕业作品不砍。

## Week -1（在 8 周外面）

还不能独立写出一个带 `if` 和列表的脚本时，先不要进第 0 周。
花几天把 venv、`python -m pip`、读 traceback 练熟。练熟了再从日历周 1 开始。
